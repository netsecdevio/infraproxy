# InfraProxy 2.6.1

- Ships a Universal 2 application with native Apple Silicon (`arm64`) and Intel (`x86_64`) support in one download.
- Verifies both architectures in the app and every bundled Sparkle helper during each build.
- Keeps the macOS 15.5 minimum, menu redesign, provider integrations, and in-app updater from v2.6.0.
- Regression tests pass natively on ARM64 and under Rosetta for x86_64. Physical Intel hardware has not been tested.

Use **Check for Updates…** in InfraProxy to install and relaunch. Users on earlier versions without an updater can install the DMG.
